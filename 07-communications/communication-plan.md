# コミュニケーション計画

PMは3年生3名（酒井・武本・細澤）が週単位でローテーションし、週次MTGを中心にプロジェクトを運営する。

## 定例
| 会議 | 頻度 | 時間 | 参加者 | 目的 |
|------|------|------|--------|------|
| 週次MTG | 週1 | 60分 | 全員 | 進捗管理（WBS番台ごとの実績工数 vs 見積もり）、マイルストーン到達確認、MOP/TPMの計画と実績の確認、リスク監視。当週PMが運営 |
| 指導教員ミーティング | 隔週〜週1 | 30分 | PM（当週担当）+ 教員 | 進捗報告・成果物レビュー |
| デイリースタンドアップ（任意） | 随時 | 15分 | 関係メンバー | 進捗共有・ブロッカー確認 |

## コミュニケーションチャネル
| 用途 | ツール | 対応時間 |
|------|--------|---------|
| 即時連絡 | Slack / Discord | 随時 |
| 仕様議論 | GitHub Issue | 随時 |
| 成果物レビュー | GitHub Pull Request | 随時 |

## ルール
- PMは当週担当者が週次MTGの運営と議事・課題管理を行う。
- 進捗は実績工数と見積もりを対比して報告し、超過時は対応をMTGで決定する。
- リスクはリスク登録簿で管理し、週次MTGで状態を確認する。
- 重要な決定はテキスト（Issue / 議事録）で残す。
