# 使用ツール・資材

## 開発ツール
| 種別 | ツール | 用途 | アカウント管理者 |
|------|--------|------|------------------|
| ソース管理 | GitHub | ソースコード・ドキュメント管理 | チーム共有リポジトリ |
| マイコン開発 | Arduino IDE | Arduino（マスタ・スレーブ）ファームウェア開発・書き込み | 各メンバー私物PC |
| 音声合成開発 | Processing 開発環境 | 楽器音色合成・Serial受信・音声出力 | 各メンバー私物PC |
| FFT解析 | Audacity または Python（numpy / scipy.fft） | 楽器別倍音比率の調査・データ化 | 各メンバー私物PC |
| 実行環境 | PC（メンバ私物） | 上記ツールの実行 | 各メンバー |
