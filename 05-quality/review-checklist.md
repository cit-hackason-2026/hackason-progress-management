# レビューチェックリスト

「Arduinoオーケストラ」開発（Arduino／Processing）向けのレビュー観点。

## コードレビュー（共通）
- [ ] 関連FBS/MOPの要件を満たしているか
- [ ] 命名が適切か（part_id・entry_offset・global_bar 等の規約に沿うか）
- [ ] 例外・異常系（SYNCミス・パケットロス）の処理が妥当か
- [ ] 対応するテスト・動作確認が行われているか

## コードレビュー（Arduino）
- [ ] 楽譜データが PROGMEM に格納され、pgm_read_byte() で読み出されているか
- [ ] I2Cフレーム（SYNC/START/STOP/CONFIG）が仕様（Wireバッファ32バイト以内）に準拠しているか
- [ ] PLL補正係数が0.3、誤差50ms超で強制スナップになっているか
- [ ] BPM変化制限（1小節あたり最大10BPM）・小節頭でのみBPM適用が実装されているか
- [ ] my_local_bar = global_bar − entry_offset の輪唱位置計算が正しいか
- [ ] BPMエンコード（bpm×10、uint16_t）の符号化・復号が一致しているか
- [ ] ISR（onReceive）はフラグ引き渡しのみで重い処理を含まないか

## コードレビュー（Processing）
- [ ] 倍音加算合成＋ADSRが各楽器パラメータで実装されているか
- [ ] Serial 115200bps の2バイトフレーム受信・パース・dispatch が正しいか
- [ ] 再トリガ前のRelease（クリック回避）が確実か

## 単体テスト合格基準（通信疎通）
- [ ] T-1：SYNCを100回ユニキャストし、各スレーブの受信カウントでパケットロス0回
- [ ] T-2：CONFIGを各スレーブへ送信し、4スレーブ全てが正しいentry_offsetを受信

## デモレビュー（輪唱演奏デモ）
- [ ] CONFIG→START→12小節完走のハッピーパスが通るか
- [ ] 各Slaveが正しいentry_offset（フルート=0／クラリネット=2／オルガン=4）で入るか
- [ ] 楽器間同期誤差が ≤30ms か（シリアルログ確認）
- [ ] ポテンショメータ操作でBPMが演奏中に追従するか（反映1小節以内・収束 変化量÷10小節以内）
- [ ] 異常系（音切れ・同期ずれ・クラッシュ）の挙動を説明できるか

## エンターテインメント機能テスト（tab:testspec）
- [ ] ロードセル単体検知：荷重印加でLOAD_THRESHOLD超過、3回連続成功
- [ ] しきい値調整：LOAD_THRESHOLD設定値で10回中10回正常検知
- [ ] サーボ停止値キャリブレーション：SERVO_STOP送信後5秒以上静止
- [ ] 状態遷移：IDLE→PLAYING→FINISHED→IDLE が正順で遷移
- [ ] 自動リセット：FINISHED遷移から30秒±2秒でIDLEへ復帰
- [ ] チャタリング除去：1周につき遷移メッセージが1回のみ出力
- [ ] PLAYING中はロードセル検知を無視しているか

## 発表レビュー
- [ ] 課題 → 解決策 → 輪唱演奏デモ → 展望の流れ
- [ ] 主観評価アンケート結果（MOP3〜5）を提示できるか
- [ ] スライドの誤字脱字
- [ ] 時間内に収まるか
