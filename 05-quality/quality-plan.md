# 品質マネジメント計画

「Arduinoオーケストラ：きらきら星 輪唱演奏システム」の品質目標・基準・レビュープロセスを定める。

## 品質目標
- MOE1〜4 を達成する（輪唱演奏の成立・きらきら星の識別・リラクゼーション・可変テンポ制御）
- MOP1〜7 を全て合格させる
- 演奏完走率：5台接続・12小節輪唱を10回連続完走（MOP2）
- 楽器間最大同期誤差：≤30ms（MOP1）
- 主観評価アンケート（楽曲識別・楽器識別・リラクゼーション）：平均≥3.5かつ標準偏差≤1.0（MOP3〜5）
- 最終デモで再現可能な演奏シナリオを用意する

## 品質基準
| 観点 | 基準 |
|------|------|
| コード（Arduino） | I2Cフレーム仕様準拠・PROGMEM読み出し正常・PLL補正係数0.3／50msスナップ実装、Arduino IDEでビルド通過 |
| コード（Processing） | 倍音加算合成＋ADSRが各楽器パラメータで動作、Serial 115200bps受信パース正常 |
| 単体テスト | 通信疎通テスト T-1（SYNC 100回ユニキャストでパケットロス0回）・T-2（CONFIG送信で4スレーブ全て正常受信）に合格 |
| 結合テスト | 全体結合演奏テスト（CONFIG→START→12小節完走、同期誤差≤30ms）に合格、可変テンポ動作検証に合格 |
| 主観評価 | 第三者3名以上による試聴アンケート（5段階評定尺度）を実施 |
| ハードウェア | エンターテインメント機能テスト（ロードセル検知・しきい値調整・状態遷移・自動リセット）に合格 |
| ドキュメント | 計画書・設計書（01-integration）に起動・配線・テスト手順を記載 |

## レビュープロセス
- PR作成 → PM（3年生：酒井・武本・細澤）が最低1名レビュー承認 → マージ
- 重要機能（同期制御・PLL補正・音色合成）は対面デモレビューで動作確認
- 統合フェーズ（WBS3）では全員参加の対面デモレビューで輪唱演奏を確認する
- 未達・重大バグは [decision-log](../01-integration/decision-log.md)・[risk-register](../08-risk/risk-register.md) へ連携
