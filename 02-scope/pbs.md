# PBS（Product Breakdown Structure / 製品分解構造）

**作成フェーズ：基本設計**

[FBS](./fbs.md) で定義した機能を実現する「製品（コンポーネント）」を階層的に分解する。
本システムは7つの製品（P1〜P7）から構成される。

## 1. システム全体構成
```
Arduinoオーケストラ：きらきら星 輪唱演奏システム
├── P1. マスタシステム（Arduino Uno マスタ・ポテンショメータ・I2Cプルアップ抵抗）
├── P2. 楽器スレーブシステム（Arduino Uno×3：フルート/クラリネット/オルガン＋USBケーブル）
├── P3. リズムスレーブシステム（Arduino Uno：ドラム＋USBケーブル）
├── P4. エンターテインメント装置（連続回転サーボ・ロードセル＋HX711・アーム・台座）
├── P5. 音声合成PC（Processing実行PC）
├── P6. 通信・電源インフラ（SDA/SCL配線・I2Cプルアップ抵抗・USB電源）
└── P7. 筐体・ソフトウェア（マウント筐体・Arduino/Processingスケッチ・楽譜データ）
```

## 2. コンポーネント分解
### P1. マスタシステム
- P1.1 Arduino Uno（マスタ）：BPMセンサ入力・SYNC配信・START/STOP制御
- P1.2 ポテンショメータ（BPMセンサ）：10kΩ、analogRead()でBPM変換
- P1.3 I2Cプルアップ抵抗：配線長・電圧に応じた定数（回路図参照）

### P2. 楽器スレーブシステム
- P2.1 Arduino Uno（楽器スレーブ×3）：フルート(0x10)・クラリネット(0x11)・オルガン(0x12)
- P2.2 USBケーブル（×3）：Serial 115200bps、Arduino→Processing PC接続

### P3. リズムスレーブシステム
- P3.1 Arduino Uno（リズムスレーブ）：Drum(0x13)
- P3.2 USBケーブル：Serial 115200bps、Arduino→Processing PC接続

### P4. エンターテインメント装置
- P4.1 連続回転サーボ：PWMパルス幅で回転速度制御
- P4.2 ロードセル＋HX711モジュール：荷重検知用（DATピン：D3、SCKピン：D4、しきい値：実測調整）
- P4.3 アーム・星形飾り：グルーガンでシャフト固定
- P4.4 エンターテインメント台座：サーボ・センサ固定用マウント

### P5. 音声合成PC
- P5.1 Processing実行PC：4種類の楽器に対応したProcessingインスタンスを起動、兼 音声出力先

### P6. 通信・電源インフラ
- P6.1 I2Cバス配線（SDA/SCL）：5台Arduino間、プルアップ実装済み
- P6.2 Arduino用電源・接続ケーブル：USB電源供給ケーブル

### P7. 筐体・ソフトウェア
- P7.1 Arduinoマウント筐体：5台Arduino収容・固定、発表展示用
- P7.2 ソフトウェア一式：Arduinoスケッチ・Processingスケッチ・楽譜データ
