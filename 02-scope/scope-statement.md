# スコープ記述書

## プロダクト概要
複数のArduinoマイクロコントローラをI2Cハイブリッド同期方式で連携させ、童謡「きらきらぼし」を主旋律3パート（フルート・クラリネット・オルガン）＋ドラムで自動輪唱演奏する装置「Arduinoオーケストラ：きらきら星 輪唱演奏システム」を開発する。
大学生のストレス回復を支援する受動的環境介入装置であり、利用者の能動的操作を要求せず大学空間に常設できることを目指す。

## スコープ（In Scope）
- 含める機能：
  - Arduino 5台構成（指揮者1台＋楽器スレーブ3台＋リズムスレーブ1台）による「きらきら星」12小節（4/4拍子）の自動輪唱演奏装置の設計・実装
  - I2Cハイブリッド同期方式（小節頭SYNCマーカー＋PLL位相補正）の実装
  - フルート・クラリネット・オルガン・ドラムの倍音加算合成による音色実装（Processing側）
  - ポテンショメータによる可変テンポ制御（BPM変更・PLL収束）の実装
  - ロードセル検知・連続回転サーボモーターによるエンターテインメント機能の実装
  - 装置単体での動作検証（同期精度・音響品質・連続演奏完走率）
- 対象ユーザー：大学生（ストレス回復支援の対象）
- 対象プラットフォーム：大学空間に常設する装置単体（Arduino Uno 5台＋Processing実行PC）

## スコープ外（Out of Scope）
- やらないこと：
  - 社会的効果検証実験（被験者を対象とした急性ストレス回復効果の実証）
  - 利用者の能動的操作を前提とする機能（アプリ操作・予約等）
  - 商業空間向けBGMサービスとしての展開
- 将来検討：社会的効果検証実験を将来研究として別途計画する（本計画書は装置構築までを対象とする）

## 受け入れ基準
- [ ] MOE1：輪唱演奏として音楽的に成立すること
- [ ] MOE2：聴取者が「きらきら星」と識別できること
- [ ] MOE3：聴取者がリラックスできること
- [ ] MOE4：センサ（ポテンショメータ）による可変テンポ制御が演奏中に機能すること
